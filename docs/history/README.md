# Hardware history

These snapshots preserve earlier reports without making conflicting wiring or manual procedures current instructions. Follow [HARDWARE_SETUP.md](../HARDWARE_SETUP.md) for the latest user-reported arrangement and verification boundaries. The historical UART0/direct-adapter experiments differ from the latest reported UART2 arrangement. Neither has been independently checked in this release pass. No old command authorizes opening COM9, resetting, powering or programming the present assembly.
